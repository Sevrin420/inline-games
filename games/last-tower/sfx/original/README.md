a short arena echo, trimmed and loudness-normalized, mono 48 kbps mp3. Generic phrases only; no third-party recordings.
Lines: slayer, double, triple, overkill, killtacular, spree (killing spree), frenzy (killing frenzy), riot (running riot), rampage,
untouchable, unstoppable, boktacular, eggster (egg-stermination), fowl (fowl play), gameover, billions (billions must bok).
