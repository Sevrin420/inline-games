# Original announcer voice (Last Tower v19)

Made on the build box with espeak-ng 1.52 (voice en-us+m3), then ffmpeg: pitched down ~22%, bass + presence EQ, heavy compression,
a short arena echo, trimmed and loudness-normalized, mono 48 kbps mp3. Generic phrases only; no third-party recordings.
Lines: slayer, double, triple, overkill, killtacular, spree (killing spree), frenzy (killing frenzy), riot (running riot), rampage,
untouchable, unstoppable, gameover. v21: this voice only plays with `?announcer=original` (the default is the Halo announcer in
`../halo/`); the chicken-pun lines (egg-stermination, boktacular, fowl play, billions must bok) were removed.
