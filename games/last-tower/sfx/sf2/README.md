# sfx/sf2: Street Fighter II UI sounds (Zombie Farm v21)

**Street Fighter II sound effects © Capcom, used under the site owner's parody license.**

The clips are the SNES Street Fighter II / II Turbo rip ("Sound Effects" by the shirt ninja on The Sounds Resource,
https://www.sounds-resource.com/snes/streetfighteriistreetfighteriiturbo/sound/34143/). The direct download from there is
Cloudflare-blocked from the build box, so the files were taken from a GitHub copy of the same pack with identical file names
(DocDamage/fighter). Each clip was trimmed, loudness normalized (-16 LUFS), and converted to mono 44.1 kHz 96 kbps mp3.
